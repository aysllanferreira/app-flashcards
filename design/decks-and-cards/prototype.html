Decks and Cards Prototype

The Paper direction for issue #61: the deck list, a deck's page, the note editor and the card browser, plus their empty, loading, error and delete states. Every screen is shown at 375 px and 1280 px; switch each frame between light and dark.

Deck listDeck pageNote editorCard browserStates

Deck list

/decks

Home for signed-in users. Counts include subdecks: new in green, due in terracotta, total in grey. Zeros fade back so the numbers that need attention stand out.

Deck page

/decks/[id]

One deck with its own figures, its subdecks and its cards. Rename and Move open dialogs; Delete deck lives in the overflow menu and always confirms.

Note editor

/notes/new · /notes/[id]/edit

A Cloze note with two deletions, so the preview shows two cards. Fields allow bold, italic and underline; Cloze wraps the selection in the next number. The preview renders in a sandbox with the note type's own CSS; in the dark theme it uses Anki's night colors.

Card browser

/cards

A dense table from 768 px with monospace dates; below that, each card becomes a stacked row. Search matches the sort field; the deck filter includes subdecks; Load more follows the cursor.

Empty, loading and error on the deck list, the delete confirmation on the deck page, and the navigation sheet that replaces the sidebar below 1024 px.
